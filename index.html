Font to Binary Converter でできること

入力した文字を、選んだフォントで 1 文字ずつドット（0 と 1）の表に変換し、C / C++ / Arduino（PROGMEM）/ Python / JavaScript / TypeScript / Rust / Go / JSON などのソースコードとして書き出します。OLED や LED マトリクス、液晶にマイコンで文字を出すときの、フォントデータ作りに使えます。インストールは要らず、変換はすべてブラウザの中で行います。

  • フォント: 美咲フォント（8×8 ドットの日本語フォント）と DotGothic16（16×16）を同梱。手持ちの TTF / OTF / WOFF / WOFF2 も読み込めます
  • 出力の形: 0 と 1 の 2 次元・3 次元の配列、1 次元に並べた配列、行方向・列方向のビットパック（8 ドットを 1 バイトに詰める形）。MSB / LSB、10 進・16 進・2 進、0 と 1 の反転を選べます
  • 手直し: プレビューの文字をクリックすると、1 ドットずつ描き直せます。自由モードでは、最大 256×256 ドットのキャンバスに描いたドット絵をそのまま配列にできます
  • 保存と共有: 設定はこのブラウザに自動で保存され、共有ボタンで同じ設定を開く URL をコピーできます

作者のサイトでの紹介: Font to Binary（takushio2525.com）

使い方ガイド

  • Arduino と OLED（SSD1306）で日本語を表示する

    表示したい文字だけを美咲フォント 8×8 の配列にして、日本語フォントのライブラリなしで OLED に出す手順。

  • 8×8 LED マトリクス（MAX7219）に文字を出す

    1 文字 8 バイトの配列を setRow で 1 行ずつ送る方法と、列方向の配列で文字を流す方法。

  • 出力の読み方：ビットパックと MSB / LSB

    行方向・列方向・ビット順の違いと、Adafruit_GFX・U8g2・MicroPython などに合わせる設定の対応表。

よくある質問

読み込んだフォントや入力した文字は、どこかへ送信されますか？

送信しません。変換はすべてブラウザの中で行い、読み込んだフォントファイルや入力した文字をサーバーへ送ることはありません。設定はこのブラウザの LocalStorage に保存されます。ページの閲覧は Google アナリティクスで計測していますが、共有 URL に入る設定（?s=）は計測に送らないようにしています。

どのフォントが使えますか？

美咲フォント（8×8 ドットの日本語フォント）と DotGothic16（16×16）を同梱しています。ほかに、システムの等幅フォントと、手持ちの TTF / OTF / WOFF / WOFF2 のファイルを読み込んで使えます。

Arduino で使うにはどうすればよいですか？

かんたんモードの出力フォーマットで「Arduino / C言語」を選ぶと、PROGMEM（フラッシュメモリ）に置く uint8_t の配列として出力します。行方向に 8 ドットを 1 バイトへ詰めた形で、Adafruit_GFX の drawBitmap にそのまま渡せます。手順は使い方ガイドで説明しています。
